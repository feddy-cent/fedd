# CS140 Homework: Linktree Replica 

Welcome to your next web development challenge! This assignment involves creating a simple HTML/CSS site that replicates the functionality of a LinkTree page. Your task is to use the provided starter code to customize and enhance a personal link hub.

[View the example here](http://167examples.azurewebsites.net/cs140/inclass2/)

## Assignment Objectives

- **Add 3 Links**: Incorporate three hyperlinks to your favorite websites or social media profiles.
- **Update Profile Image**: Replace the placeholder image with a personal or preferred image.
- **Customize Background**: Choose a background color or image to personalize your page.
- **Modify Page Title**: Update the `<title>` tag in the HTML to reflect your project or name.
- **Personalize with Your Name**: Ensure your name is prominently displayed on the page.

## Instructions

1. **Access Assignment**: Click the GitHub Classroom link provided to accept and access the assignment repository.
1. **Open Repository**: Open your assignment in GitHub Codespaces for online editing.
1. **Review Starter Code and Example**: Begin by examining the HTML and CSS files. Look for comments that guide where to make specific changes.
1. **Perform Updates**: Follow the assignment objectives to customize your site.
1. **Preview Changes**: Use a local server or open the HTML file in a browser to see your changes.
1. **Submission**: Download the files, compress them (zip is easiest) and upload to brightspace
## Tips

- Pay close attention to the HTML comments (`<!-- Comment -->`) for guidance on where to add or update content.
- Experiment with CSS styles to make your links stand out and reflect your personal brand.
